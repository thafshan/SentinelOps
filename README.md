SentinelOps

SentinelOps is a full-stack IT operations and security monitoring platform designed to help organizations manage assets, track vulnerabilities, monitor security events, and handle incidents.

Project Goals
Build a modern full-stack application using React and TypeScript.
Develop backend services using Python and FastAPI.
Use PostgreSQL and SQL for relational data management.
Implement authentication and role-based access control.
Develop Python-based security event processing.
Apply secure software development practices.
Practice testing, Docker, CI/CD, and deployment.
